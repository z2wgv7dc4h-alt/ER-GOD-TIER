## 110 — Build lab power tools (owns `src/Build.tsx`, `src/library/BuildPlanner.tsx`, `src/lib/advisor.ts`, new `src/build/*`)
1. **Loadout presets**: save named loadouts (weapons, armor, talismans, spells) per profile; switch in one
   tap; each preset shows AR (right-hand 1), equip load % + class, poise. Stored in the vault.
2. **Stat planner**: sliders for the eight stats from current values up to +N levels; live readouts of HP, FP,
   stamina, equip load, AR of equipped weapon, soft-cap markers; "Apply as target" → respec plan.
3. **Level-up calculator**: input current runes → how many levels affordable (Elden Ring rune cost formula per
   level), and where the advisor would put them.
4. **Smithing tracker**: for each owned weapon, stones needed to reach +N (by type: Smithing / Somber),
   owned counts if known, and farm locations (gathering/enemy drops) with Show on map.
5. **Verdict fix**: when no weapon is equipped, Library cards must not say "Upgrade" on everything — show
   "Usable" (requirements met) or the "Needs …" badge; "Upgrade +N%" only against a real equipped weapon.

## 111 — Map power tools (owns `src/Atlas.tsx`, `src/shell/MapControls.tsx`, `vendor/elden-ring-map/web/**`, new `src/map/*`)
1. **Answer pins**: any entity opened / Gideon answer / search hit with a location drops a temporary "result"
   pin; "Show on map" centres on it with a pulse.
2. **Custom notes**: long-press (phone) / right-click (desktop) the map to drop a note pin with text and an
   optional linked entity; list them under Journey › Map › Notes; stored in the vault.
3. **Follow mode**: toggle that keeps the map centred on `currentArea` (grace coords); on PC with the live dot,
   follow the dot.
4. **Undone heat**: toggle a layer showing density of not-done bosses/items per area.

## 112 — Player settings & tracking (owns new `src/settings/*`, `src/shell/MeProfiles.tsx`, `src/lib/spoilers.ts`, new `src/watch/*`)
1. **Settings** under Tarnished › Profiles: text size (S/M/L), reduce motion, default landing section, spoiler
   level, Gideon AI key status + "Test connection" button, haptics on/off, data freshness (which datasets are
   cached) + "Download all for offline".
2. **Spoiler levels**: none / light / full. Light blurs names of bosses, NPC fates and endings in regions not yet
   reached (tap to reveal); none hides lore tabs for unreached content. Apply in Library, Area, Quests,
   Gideon answers via one `useSpoiler(factId)` helper.
3. **Watchlist**: star any entity (button on the entity page); Journey › Now shows a Watchlist card; starred
   items get map pins (expose a `watchPins()` function Task 111 can consume later).
4. **Journal**: Tarnished › Overview "Journal" — timeline of logged facts with dates (from evidence/source),
   filter by type, export as Markdown.
5. **Haptics**: `navigator.vibrate(15)` on log/mark/apply when enabled (guarded).
