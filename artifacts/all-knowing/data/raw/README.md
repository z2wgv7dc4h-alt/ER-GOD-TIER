# `data/raw/` — raw, gitignored data drops

This folder holds **large raw data drops that are too big (or too game-derived) to
commit**. Everything here is gitignored except this README, so a fresh clone has
an empty `data/raw/` and the scripts that need it say so instead of silently
using a stale file.

## `er-mcp.db` — Fandom wiki SQLite snapshot

The 47 MB `er-mcp.db` is the scraper output of
[`teoucsb82/elden-ring-mcp`](https://github.com/teoucsb82/elden-ring-mcp)
(release asset `elden-ring.db`, tag `data-2026.09.21`). It is a versioned dump of
the Fandom Elden Ring wiki and is the richest structured+prose source in the
project.

Download it into this folder:

```sh
curl -L -o data/raw/er-mcp.db \
  https://github.com/teoucsb82/elden-ring-mcp/releases/download/data-2026.09.21/elden-ring.db
```

### What it contains

| table | rows | contents |
| --- | --- | --- |
| `pages` | 4,939 | one row per wiki page: title, url, revid, full `wikitext`, DLC flags |
| `sections` | 21,885 | ordered wikitext sections (`heading`, `markdown`) |
| `redirects` | 2,730 | redirect title → target title + fragment |
| `entities` | 1,694 | typed pages (weapon / armor / spell / boss / talisman) |
| `weapons` | 480 | parsed weapon infobox (type, weight, requirements, scaling, skill) |
| `armor` | 680 | parsed armor infobox (slot, weight, poise, effects) |
| `spells` | 213 | parsed sorcery / incantation rows |
| `talismans` | 156 | parsed talisman rows |
| `bosses` | 165 | parsed boss rows (location, HP, runes, drops) |
| `acquisition` | 2,609 | item → how obtained (method, location, nearest grace, prereqs, missable) |
| `quests` | 341 | NPC quest steps (order, location, action, breaks quest) |
| `sections_fts` | 21,885 | FTS5 full-text index over sections |
| `sync_state` / `dlc_report` / `dlc_categories` / `extract_failures` | — | scrape metadata |

Counts are current as of the `data-2026.09.21` snapshot; `docs/DATA-CATALOG.md`
(regenerated by `npm run data:catalog`) is the authoritative, always-current
census of every table and every infobox/category found in `pages.wikitext`.

### How it is consumed

```sh
python scripts/export-mcp-db.py          # -> public/sourced/open/{acquisition,npc-quests,recipes,wiki-sections,secrets}.json
```

`scripts/export-mcp-db.py` joins `pages`/`sections`/`acquisition`/`quests` into
the committed JSON the app fetches (`src/lib/acquisition.ts`, `npcQuests.ts`,
`recipes.ts`, `wikiText.ts`, `secrets.ts`). The typed tables (`weapons`, `armor`,
`spells`, `talismans`, `bosses`) and `redirects` are **not yet mined** — see
Task 131 §3 and the Gaps section of `docs/DATA-CATALOG.md`.

## Rules

- Do **not** commit anything under `data/raw/` — it is gitignored on purpose.
- Do **not** read `.env` files.
- Never report data as missing without checking `docs/DATA-CATALOG.md` first.
